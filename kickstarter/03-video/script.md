# ChatScan Kickstarter video script (60–90 seconds)

## On-screen structure

1. **0–8s — Hook**  
   VO: “Block explorers show crypto transactions. ChatScan shows encrypted messages — without ever showing the message.”  
   Visual: ChatScan homepage hero + CrypterChat logo.

2. **8–25s — Problem**  
   VO: “Private chat should stay private. But communities still need a public way to prove a message commitment was recorded.”  
   Visual: Highlight breadcrumb stats / server active toggle.

3. **25–50s — Demo**  
   VO: “Every CrypterChat message appears as HASH slash ID. Contents are end-to-end encrypted and not viewable.”  
   Visual: Scroll Hash ID table → click a ref → detail panel shows content note “not viewable.”  
   Action: Submit a new 64-char hash → new `hash/id` appears.

4. **50–70s — Roadmap ask**  
   VO: “We’re building ChatScan for the X11 Blockchain. Your pledge funds chain integration, security review, and the CrypterChat bridge.”  
   Visual: GitHub repo / X11 mention on page.

5. **70–90s — CTA**  
   VO: “Back ChatScan. For the people who value online privacy.”  
   Visual: End card with Kickstarter URL placeholder + crypter.chat / chatscan.org

## End card text

```text
ChatScan Block Explorer
CrypterChat × X11
Back the project on Kickstarter
github.com/crypterchat/chatscan
```

## Production notes

- Keep music subtle; prioritize voice clarity.
- Do not show any real private message text — only hashes.
- Captions recommended (accessibility + silent autoplay feeds).
