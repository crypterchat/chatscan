# Kickstarter upload checklist

- [ ] Create Kickstarter project (creator account verified)
- [ ] Paste title from `01-campaign/title.txt`
- [ ] Paste subtitle / blurb from `01-campaign/`
- [ ] Set category Technology → Apps
- [ ] Set funding goal **$15,000** (`02-funding/recommended-goal.txt`)
- [ ] Set duration 30–35 days
- [ ] Upload `03-video/chatscan-kickstarter-campaign.mp4`
- [ ] Paste story from `01-campaign/story.md`
- [ ] Add rewards from `02-funding/rewards.md`
- [ ] Upload gallery images from `04-assets/`
- [ ] Read `05-legal/kickstarter-disclaimer.md` (rewards ≠ equity)
- [ ] Build prelaunch email/social list before going live
- [ ] Review funding scenarios in `02-funding/funding-estimate.md`
