# Kickstarter upload file map

Use this folder as your campaign kit. Upload files into Kickstarter in the order below.

```text
kickstarter/
├── FILEMAP.md                          ← you are here
├── 01-campaign/
│   ├── title.txt                       ← project title
│   ├── subtitle.txt                    ← short tagline
│   ├── short-blurb.txt                 ← Kickstarter blurb (≤135 chars ideal)
│   ├── category.txt                    ← recommended category
│   └── story.md                        ← full campaign story (paste into editor)
├── 02-funding/
│   ├── funding-estimate.md             ← how much you can realistically raise
│   ├── recommended-goal.txt            ← suggested primary goal
│   ├── rewards.md                      ← reward tiers to copy
│   └── budget-breakdown.md             ← where the money goes
├── 03-video/
│   ├── script.md                       ← 60–90s voiceover script
│   ├── recording-notes.md              ← recording + upload tips
│   ├── chatscan-kickstarter-campaign.mp4  ← **upload this** (title + demo + end)
│   └── chatscan-kickstarter-demo.mp4   ← raw UI walkthrough
├── 04-assets/
│   ├── logo-crypterchat.svg
│   ├── screenshot-explorer.png
│   ├── screenshot-detail.png
│   ├── screenshot-endcard.png
│   └── image-captions.md
├── 05-legal/
│   └── kickstarter-disclaimer.md       ← important: rewards ≠ equity
└── 05-upload-checklist.md              ← step-by-step Kickstarter upload
```

## Quick upload order on Kickstarter

1. Title + subtitle + category
2. Primary funding goal **$15,000** (`02-funding/recommended-goal.txt`)
3. Campaign video: `03-video/chatscan-kickstarter-campaign.mp4`
4. Story (`01-campaign/story.md`)
5. Rewards (`02-funding/rewards.md`)
6. Gallery images (`04-assets/*.png`)
7. Read funding estimate: realistic band **$15k–$40k** if funded

## Important

Kickstarter is **reward crowdfunding**, not equity investment. Backers get rewards, not shares, unless you use a separate regulated equity platform.
